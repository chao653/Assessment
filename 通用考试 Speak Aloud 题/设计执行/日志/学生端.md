### 操作摘要

- **组件宽度覆盖**：`Speak Aloud` 学生端三个变体里，`Header`、`Answer`、`Footer/Report/None/None` 这几层在母版里是固定 900 宽，放进 752 宽的 `Question Card/Student` 后会溢出（右上角分值和语言徽标被裁掉、录音区超出边框）。在每个实例上把这几层的宽度覆盖成 Fill，没有 detach，也没有改组件库。
- **题号对齐**：作答页和未评分页的底部导航当前题是 2，题卡题号改成 `2`；已评分页导航当前题是 1，保持 `1`。
- **示例数据统一**：Section 2 第 2 题，1 分，`Language: English`，Grading Difficulty = Easy (Lenient)；录音中 `0:12 / 1:40`；已保存录音 `0:08`。题干和目标句沿用组件默认文案。
- 克隆来的外壳里，`Frame 2611087` 改名为 `Action Row`；顶栏、导航等共享组件内部的无语义图层名属于组件库，没有动。

### 已确认（来自 PRD / Linear）

- 学生端沿用通用考试外壳（题号、上一题 / 下一题、计时、提交、`Mark for Review` 常驻），单栏，不用阅读双栏。
- **学生不能回放自己的录音**，回放只给老师（PRD §4、§7）。
- 录音流程：`Tap to Speak` → 录音中（听到目标句每个词后自动停止，或 100 秒封顶；学生也可以手动停）→ `Processing...` → `Audio recorded`。
- `Try again` 只在老师开了 Allow Try Again（默认关）且考试未提交时出现；点了以后清掉当前录音、回到未录音，只按最后一次保存成功的录音计分。
- 录音中离开本题或本页，正在录的内容作废；没保存成功的录音在提交 / 自动提交时算未作答。
- 麦克风被禁用：本题未作答，学生可以继续做其他题，**不算违规**。保存失败：可以重录，本题保持未作答（或保留上一次保存成功的录音）。
- 计分：每个词都达到本题 Grading Difficulty 的标准 → 满分，否则 0 分，没有部分分。没听到语音 → 0 分、Insufficient Response。自动评分不可用 → Needs grading，暂无最终分。

### 设计判断（可推翻）

1. **使用待归档库的组件**：项目 Figma 偏好规定 `Kira Custom Components (TO BE ARCHIVED)` 不用于新稿，本次按用户明确指定使用该库的 `Speak Aloud` 组件。
2. **列结构**：参照 Multiple Choice 页 Single Answer Student 的「考试中 / 已提交未打分 / 已打分」三段，把考试中拆成 Record Answer、Try Again、Recording Errors 三列，标题卡用英文（和同页 Teacher Section 一致）。
3. **Insufficient Response 的题卡徽标用 `Incorrect`**：学生端 `Questions Answer State` 只有 Correct / Incorrect / Not Answered / Rubric Graded，没有 Insufficient Response；音频行显示 `Recording saved · no speech detected`。
4. **Needs Grading 用未评分题卡（`— / 1 pts`）**，放在已评分报告里，导航当前格用中性的选中样式（`feedback=off, State=Selected`），因为导航格组件在 feedback 开启时没有中性色。
5. **Explanation 文案是本次写的**：Incorrect `Some words didn't meet the Easy (Lenient) bar.`；Insufficient Response `No speech was heard in this recording.`；Not Answered `No recording was saved, so this question scores 0.`。Correct 沿用组件默认 `Every word matched the target text at the Easy (Lenient) bar.`
6. **已评分页导航当前格颜色和结果同步**（Correct 绿、其余红）。Multiple Choice 的先例稿没有同步，这里同步了，避免题卡和导航对不上。
7. **没画麦克风悬停态**：组件库本地已有新的 `Speak Aloud / Microphone Button`（Idle / Recording × Default / Hover / Pressed），但还没发布，Question Library 里拿到的已发布版本没有这个变体。
