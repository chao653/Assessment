### 三个方案

| 方案 | 思路 | 优点 | 取舍 |
| --- | --- | --- | --- |
| A · Recorder Bar | 目标句放在浅灰阅读框里，下面一条固定高度的录音条装下所有状态 | 卡片最矮，80 词目标句和 Next 也能留在首屏；状态切换时页面不跳；看起来像考试里的其他作答行 | 按钮只有 40px；提示文字要写短 |
| B · Reading Stage | 目标句 24px 当主角，所有操作放在同一面板底部的操作坞；录音时面板顶部细条显示 100 秒上限的用量 | 对低年级最好读；所有操作只在一个位置；出错只染底部操作坞，正文照样可读 | 卡片最高，80 词时操作坞会掉到首屏以下；字号比同场考试其他题型大 |
| C · Progress Tracker | 面板顶部「Microphone → Record → Save」三步追踪器，每个状态点亮一步，出错标在失败的那一步 | 学生一眼能看出答案存好没有；错误直接指向麦克风还是保存；适合第一次在考试里录音的学生 | 每道 Speak Aloud 都多一行进度；浏览器允许麦克风之后，第 1 步在后面每题都是已完成 |

### 用到的设计系统

- 颜色、间距、圆角、文本样式全部绑定 `Design System 2.0 Foundations`：`text/*`、`icon/*`、`fill/*`、`border/*`、`surface/*`、`spacing`、`radius`、`text/{scale}/{weight}`。
- 按钮、徽标用 `ShadCN-Default` 的 `Button`（Default / Outline / Ghost / Destructive，Size default / sm / icon，State Default / Loading / Disabled）和 `Badge`。
- 图标全部来自 `Design System 2.0 Icons`（Phosphor）：Microphone、MicrophoneSlash、Stop、Check、CheckCircle、CircleNotch、ArrowCounterClockwise、WarningCircle、Globe、PauseCircle、Timer、X。
- 考试外壳克隆自 Student Section 的作答页，只把 `Question Card/Student` 换成方案题卡。
- 新稿没有使用待归档的 `Kira Custom Components` 组件。

### 设计判断（可推翻）

1. **已录音不用绿色**：现有组件录完是绿底加对勾，考试里绿色会被读成「答对了」。三个方案都改用品牌色或中性色。
2. **错误只染局部**：现有组件出错时整块录音区变红，三个方案只给录音条、操作坞或进度面板染浅色。
3. **麦克风被禁用的按钮改叫 `Check again`**：避免和 Allow Try Again 的 `Try again` 同名。
4. **分值写 `1 pt`**（单数）。
5. **PRD 固定文案保留**：`Tap to Speak`、`Processing...`、`Audio recorded`、`Try again`。
6. **新增 4 个状态**：等待麦克风授权、最后 10 秒提醒、Try again 二次确认、录音不可用。
7. **学生仍然不能回放录音**（PRD §4、§7），三个方案都没有播放按钮。
8. **录音进度条用自绘条**：ShadCN `Progress` 只支持 0 / 25 / 50 / 75 / 100%，所以 B 的时间条用 token 自绘。

### 方案 D 怎么做的

- **完全沿用 lesson 的**：居中吉祥物、居中说明文字、30px 加引号目标句（`text/3xl/medium`）、Outline lg 的 `Tap to Speak`、胶囊波形条、「× 丢弃 / ✓ 完成」圆形按钮、录音结束后两个按钮都变灰（对应 lesson 的 Recording Complete）、Outline 的 Try again 按钮。

### 操作摘要

- 结构和视觉照搬 Question Library 里的方案 D，用 Foundations token、ShadCN `Button` / `Avatar=Mascot`、DS 2.0 Icons 在组件库文件里重新搭建（跨文件不能直接复制节点）。
- 卡片所有内层都是填充宽度：卡片拉到 960 宽时，目标句和 Recorder 跟着填满到 894。现有 `Speak Aloud` 组件 `Header` / `Answer` 固定 900 宽的问题，这里没有。
- 绑定检查：两个组件里 342 个自建图层的颜色、描边、间距、圆角都绑定了 token。组件集自带的默认白底已绑到 `surface/layer/primary`。只有波形条的 3px 间距和条宽是有意写死的几何尺寸。
- 中途有两次调用超时。第一次其实已经完整执行；第二次多建了 6 个单独的重复组件，已按确切 ID 删除。

### 设计判断（可推翻）

1. **拆成两个组件**：录音控件状态多（11 个），单独做成 Recorder 组件集；卡片只有一个，通过暴露实例切状态。避免卡片本身变成 11 个变体，改版式时只改一处。
2. **目标句的引号写在文字里**：线上 lesson 会按语言加引号（法语界面是 « »），研发实现时由 UI 加，不要让老师输入引号。
3. **分值默认 `1 pt`**（单数）。
