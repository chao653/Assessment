## 结论

**流程**：学生端作答主线完整，包括看题、录音、处理、已录音、Try again、麦克风被禁用 / 保存失败、暂停 / 锁定，以及报告页的 7 种结果。还缺 3 段：

1. **随测评提交**（ticket 原文）：没有稿体现「录好的题在导航里算已答」，也没画「录音中 / 处理中就提交」。
2. **录音中离开本题**：PRD 写作废，没有稿，也没有提示文案。
3. **老师播放录音、看评分状态**（ticket 原文）：不在学生端 Section 里。已知的 Figma 稿里，Monitor、作答抽屉、成绩页都没有（详见 E）。

**信息**：这轮发现 2 处稿子本身的错误，已改：已评分页单词块颜色和结果矛盾，报告页底部被裁切。另有 6 处组件层面不一致，需要组件负责人处理；5 项需要 PM 确认。

## C. 从 Ticket 评论里补到的信息（后端接口约定，2026-09-22）

| 接口约定 | 和稿子的关系 |
| --- | --- |
| 已答 = 成功保存了一条带 `audioFileKey` 的作答；上传失败不算已答 | 和 Save Failed 稿的「This question is still unanswered」一致 |
| Try again 只有 `enableTryAgain`（默认 false），没有次数字段 | 说明重录不限次数，R1 #13 可以按此请 PM 确认 |
| 语言只有 `en-US`（English）和 `es-MX`（Spanish） | Spanish 的样子还没画（R1 #17，可选） |
| 学生能读到 `expectedWords`（目标句）和 `question`（Instructions，可空） | 老师没写 Instructions 的样子还没画（R1 #17，可选） |
| Monitor 题型筛选里 Speak Aloud 归 Rubric Graded（2026-10-09 产品确认） | 教师端 Monitor 的事，学生端不受影响 |

## E. 教师端（Ticket 要求，学生端 Section 不含）

- Ticket 和 PRD §5 都要求老师在 **Monitor、作答抽屉、成绩页** 里播放学生最后一次录音，并看到 graded / Insufficient Response / Needs grading / unanswered。
