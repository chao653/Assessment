ACT Analytics — HTML prototypes

Two interactive layouts for the ACT teacher analytics panel, built from the Figma designs. Both use the same mock class (17 of 18 students submitted) and the same PRD rules: subject scores only (no Composite), counts instead of percentages, ACT College Readiness Benchmarks, and a 70% line for skill gaps.

Prototype A · Single column
Subject score cards → collapsible score distribution → skill gaps & students. Click a score card to switch subject, a skill row to filter the table, and any column header to sort.
Open prototype →
Prototype B · Subject tabs + skill rail
Segmented subject tabs → class average + distribution → a vertical skill rail whose selected skill drives the student list on the right (master–detail).
Open prototype →

How to use

  • The dark bar at the bottom-right switches between Default, Loading, Failed and No scores states (Prototype B also has Subject not scored).
  • Hover a histogram bar to see which students fall in that score band; hover the “—” in Charlotte Bell’s Writing cell for the no-score tooltip.
  • Deep links: v1-single-column.html?subject=science&dist=1, v1-single-column.html?skill=sci-iod, v2-vertical-tabs.html?subject=science, v2-vertical-tabs.html?skill=eng-kol (zero-weak skill).
