How to use the prototypes

  • Start Survey opens Section 1; Continue moves to the next section's intro (the questions themselves are out of scope, so the flow ends after Section 4).
  • The Prototype panel in the bottom-left corner switches layout (B / C / D), Intro content (Empty / Text / Long) and screen without leaving the page. Close it with × if it gets in the way.
  • The "Empty" Intro is the current default Intro page and is identical across proposals; it appears when the teacher has not written any instructions.
  • Images inside the teacher's instructions are shown as sized placeholders (max height 360px in B / D, 480px in C), exactly as in the Figma frames.
  • Designed at 1440px wide. Below 960px the columns stack so the pages remain readable on smaller screens.
  • Source: Ver. B · Ver. C · Ver. D in Figma.
