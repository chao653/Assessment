# R1 走查报告 · SAT Analytics（APAC-6071）

- 日期：2026-10-16
- 走查对象：[Assessment 4.0 - SAT · Analytics · SAT Analytics](https://www.figma.com/design/OVpujOifLrARaLV9F503rq/Assessment-4.0---SAT?node-id=2260-2850)，14 张状态稿、Visual Spec 规范板、「🧱 UI Components › SAT Analytics · Components」，以及 Ticket 第 1 条牵涉到的学生报告档位药丸
- 依据：[APAC-6071](https://linear.app/kira-learning/issue/APAC-6071/design-sat-analytics)、[PRD: SAT Analytics](https://app.notion.com/p/3e270a1b992480cb981ad7801d981ef1)、[原型](https://assessment-actandtcap.vercel.app/assessment-4.0.html)
- 方法：用脚本把每张稿的文案、学生表、域行、分布柱、筛选条全部抽出来，逐条和 PRD 规则核对；数字类规则（平均分、三档人数、band 人数、分母、排序）按学生表原始分数重新计算比对；Skills Insight 正文和原型里的 College Board 原文常量逐字比对。
- 结论：发现 6 处不符合，已全部在 Figma 上改掉（其中学生报告一处 staging 仍需前端跟进）；另有 4 项搁置或需确认，见 `R1_修改清单.md`。

## A. PRD 对齐

| 锚点 | 检查项 | 结果 |
| --- | --- | --- |
| Scope / §1 | 每个学生的 domain band 是 Kira 估算，UI 必须始终标注 `Estimated` | **不符合 → 已改**。14 张稿里没有一处写 Estimated。按原型在「Skill gaps & students」副标题前加 `Estimated domain bands · `（#1） |
| §1 | 不出现 Standard / Higher 路由信息（学生表、分区卡、分布图都没有） | 符合 |
| §2 | 分母按科目各算各的：R&W 17、Math 16、单科 Math 14；筛选条写成 `9 of 16 students with a Math score` | 符合 |
| §2 | Manual 未发布的学生不进统计，表头显示 `{n} awaiting release` | 符合（单科稿 `14 of 18 students scored · 3 awaiting release · 1 not started`） |
| §2 | 单科考试只显示该科的卡片、分布和 4 个域，不留另一科占位 | 符合（单科稿只有 Math 卡、Math 列，图例备注改为 `(Math 530)`，See all 8 隐藏） |
| §3 | 两张分区卡；平均分取整（R&W 8500/17 = 500，Math 8040/16 = 502.5 → 503）；`{met} of {N} met BM {bm}` + `{n} approaching`，无进度条、无红黄绿 | 符合 |
| §3 | 某科无人出分：`— / 800`，次要行隐藏 | 分区卡符合；分布区左侧 meta 卡仍显示 `No Math scores yet` 和一排 `— met or exceeded / — approaching …` → **不符合 → 已改**（#3） |
| §4 | 分布默认收起；表头 `Score Distribution · {Section}` / `{N} students scored · BM {bm}` | 符合 |
| §4 | meta 三档和 N 对得上：R&W 10+2+5=17，Math 6+2+8=16，单科 8+1+5=14 | 符合 |
| §4 | 7 个官方 band；按学生分数重算各 band 人数，R&W 1/2/5/4/3/2/0、Math 1/2/3/6/2/1/1 均一致；R&W 和 Math 的 band 3/4 区间分开写（420–480 / 490–540 vs 420–460 / 470–540），柱宽跟随区间 | 符合 |
| §4 | `BM {bm}` 标在含 BM 的柱子上（R&W Band 3、Math Band 4）；0 人不标数；图例 Above / Includes / Below BM | 符合 |
| §4 | 悬停 tooltip 最多 6 人，Math Band 4 的 6 人和学生表一致、按分数升序 | 符合 |
| §4 | 空态文案 `No {Section} scores yet — the distribution appears once students submit both modules and scoring completes.` | 符合 |
| §5 | 标题、副标题两种写法（含 `Both sections, {Section} first`）、`See all 8` / `Show less` | 符合（补 Estimated 前缀后仍保留 PRD 原句） |
| §5 | 按科目分组、已选科目在上、组内按 band 升序（同 band 时缺口多的在前）；不跨科排序；8 个域题量区间都是官方值 | 符合 |
| §5 | band 一定带区间写，不能只写 `Band {b}` | 有分数的域行符合；Math 无分稿里 4 条禁用域行写成 `Band —` + `— below benchmark` → **不符合 → 已改**（#2，按原型改为 `—` + `No scores yet`） |
| §5 | Skills Insight：独立切换；两段原文 + 顶部灰字限定语 + 底部来源行；Band 7 隐藏第二段；筛选态改用缺口学生中位数 band 和对应限定语 | 符合。Craft and Structure 的 Band 2 / 3 / 4 三段正文与 College Board 原文逐字一致 |
| §5 | 选中行有明显选中态和勾；筛选条 `{Domain} · {Section} · {N} of {M} students with a {Section} score` + 清除；Show less 下选中行置顶 | 符合 |
| §5 | 零缺口的域仍可点，表格显示 `No students match this skill gap.` | 符合 |
| §6 | 列：Student / R&W / Math，无 Total、无路由列；行数 = 至少一科有分的学生（17 / 17 / 14） | 符合 |
| §6 | 只出现 `Auto-submitted` 标签；没分的格子 `—` 不分档 | 符合 |

## B. 规范合规

| 检查项 | 结果 |
| --- | --- |
| token 绑定 | 新组件和本次改动都绑语义 token。例外：Band 3–4 底色绑原色 `yellow/100`，因为学生报告用的就是它，设计系统里没有对应的 warning 语义色（已写进组件描述） |
| auto layout / 默认白底 | 新建容器无未绑定的默认白底 |
| 命名 | 新图层命名有语义；从旧母版继承的无语义名（如组件库内部层）未动 |
| UI 文案大小写 | `See all 8`、`Show less`、`What this band means` 等按 PRD 原文 |
| 字重 | 新组件不用 semibold；旧母版里人数、平均分等数字仍是 semibold，属既有设计，未改（清单 #9） |
| 图标 | 全部是 Phosphor 组件实例 |
| 鼠标交互示意 | 悬停稿没有鼠标指针。这条规则来自脚手架草稿（未合入），本轮不作必改项（清单 #8） |
